---
name: Capturas do Atlas Premium
description: Limite editorial para prévias visuais de itens pagos do Atlas sem assinatura de teste.
---

Para entregar capturas móveis de ilustrações Premium sem uma conta autorizada, renderizar o SVG original como prancha isolada e identificar claramente que não é a ficha Premium no app. Não alterar autorização, criar assinatura de teste ou usar cabeçalho falso só para fotografar a tela.

**Why:** A captura visual solicitada não concede direito de acesso ao conteúdo pago. Uma prancha permite revisar o desenho sem produzir uma falsa evidência de acesso à ficha nem enfraquecer o paywall.

**How to apply:** Em novas etapas de ilustrações do Atlas, capturar itens gratuitos no app real; para itens pagos sem conta legítima, gerar capturas estáticas rotuladas do arquivo autoral e verificar separadamente que o endpoint privado responde 403 para visitantes.
